# Imagens dos personagens

Coloque aqui as fotos de perfil de cada personagem.
Formatos aceitos: .jpg, .jpeg, .png, .webp

## Como nomear

Use o nome do personagem em minúsculas, sem acentos e sem espaços:

| Personagem          | Nome do arquivo          |
|---------------------|--------------------------|
| Eduarda Fragoso     | `eduarda-fragoso.jpg`    |
| Marina              | `marina.jpg`             |
| Rádio da Cidade     | `radio-da-cidade.jpg`    |
| (adicione aqui...)  | `nome-do-personagem.jpg` |

## Como usar no capítulo

```
::: tweet Eduarda Fragoso | @dudafragoso | 08:42 PM · 01 jun. 26
:foto img/personagens/eduarda-fragoso.jpg
Texto do tweet aqui.
:::
```

```
::: whatsapp Marina
:foto img/personagens/marina.jpg
= Hoje
< Você viu o céu agora? | 07:12
:::
```

## Dicas

- Tamanho ideal: 200×200px ou maior (será exibido em 40×40px)
- Prefira imagens quadradas — serão recortadas em círculo automaticamente
- Mantenha arquivos abaixo de 200kb para não impactar o carregamento
